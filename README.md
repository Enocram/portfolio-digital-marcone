# Portfólio Digital — Marcone Arruda

## Sobre o Projeto

Este repositório contém o portfólio digital oficial de Marcone Arruda.

Mais do que apresentar projetos, esta plataforma foi criada para comunicar uma visão: a de que educação, criatividade e tecnologia podem caminhar juntas na construção de soluções com propósito humano.

O projeto segue os princípios do Método EduNEXUS™, priorizando simplicidade, clareza, acessibilidade e evolução contínua.

---

## Quem é Marcone Arruda?

Marcone Arruda é pedagogo, escritor, criador digital, pesquisador e idealizador do Método EduNEXUS™.

Ao longo de sua trajetória, desenvolve projetos que conectam educação, inteligência artificial, literatura, tecnologia educacional e inovação, buscando transformar conhecimento em experiências significativas e acessíveis.

## Filosofia do Projeto

Este portfólio foi construído a partir de uma ideia simples:

> Ideias merecem sair do papel.

A tecnologia é utilizada como ferramenta para ampliar possibilidades humanas, fortalecer processos educativos e transformar conhecimento em impacto real.
